# Thunde-s-GIF-Folders-for-Vencord
This is a plugin that exponentially improves on discord's native GIF saving system.



- With my plugin you have multiple folders with multiple gifs,
- You can move the gifs around in each folder by hold-clicking on a gif
- You can move them to the start or end of the folder (for having favorites within favorites)
- You can rename them to then search them in the search bar to find them instantly
- You can cache them so they open almost instantly (no more gifs not loading anymore)
- You can export them via .json or full export them on disk for backup
- You can save any .gif file or .mp4 file (20mb limit) or image file in the folders to then use later.
- You can HOLD CTRL+CLICK on a gif to send it without quitting the folder, so you can send multiple gifs in quick succession.
- Hold-click on the window's edges to resize the window to your own desire

I developed this using AI so i am not allowed to publish it to the original Vencord due to their rules, meaning that you'll have to manually install it. You can use chatgpt to help you with install instructions, it's pretty straight forward.
I want to share this plugin with the world hoping that a really skilled developer will build it from scratch the right way to add it to the original vencord.

Minor bugs exist, but they are not very annoying and i hope i'll eventually fix them. For example rarely, some mp4 saved files that you'll send, will be sent with a blue link above the video. You can re-upload it and re-save it to a folder and this gets fixed.
Also very rarely, when you save a gif/image/mp4 to a folder, discord crashes. I suspect it's some memory issue but this is happening around once a week so it's a non-issue for most people.
